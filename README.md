# 📊 Análise de Vendas

## 📌 Sobre o Projeto

Este projeto apresenta uma Análise Exploratória de Dados (Exploratory Data Analysis - EDA) utilizando o conjunto de dados da Olist, uma das maiores plataformas de e-commerce do Brasil.

O objetivo é realizar a limpeza, transformação e análise dos dados para identificar padrões de vendas, comportamento dos clientes e desempenho logístico, utilizando estatística descritiva e visualizações para gerar insights relevantes.

---

## 📁 Conjunto de Dados

O dataset contém informações sobre diferentes aspectos das operações da Olist, incluindo:

- Clientes
- Pedidos
- Itens dos pedidos
- Pagamentos
- Vendedores
- Produtos
- Informações de entrega

---

## 🛠 Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📈 Análises Realizadas

Durante o projeto foram realizadas as seguintes etapas:

- Limpeza e tratamento dos dados
- Tratamento de valores ausentes
- Verificação de registros duplicados
- Integração de múltiplas tabelas (Merge)
- Engenharia de atributos
- Análise do tempo de entrega
- Identificação de pedidos entregues com atraso
- Análise do valor médio dos pedidos
- Análise de vendas por estado
- Análise de correlação entre variáveis numéricas
- Criação de visualizações para apoio à tomada de decisão

---

## 🎯 Objetivos do Projeto

Este projeto foi desenvolvido com o objetivo de praticar e demonstrar conhecimentos em:

- Manipulação de dados com Pandas;
- Limpeza e preparação de dados;
- Análise Exploratória de Dados (EDA);
- Visualização de dados;
- Estatística descritiva;
- Geração de insights para negócios.
